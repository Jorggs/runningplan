# Running plan

A subscribable calendar of my running sessions.

Subscribe URL:

    https://raw.githubusercontent.com/Jorggs/runningplan/main/running-plan.ics

Sessions live in `plan.py`; run `python3 plan.py` to regenerate `running-plan.ics`.

## Apple Watch workouts

`workouts/` holds custom workouts for the Workout app, built by `python3 workouts.py`.
Open a `.workout` file on the iPhone to add it to the Apple Watch.
